# Solvane Frontend

### Routes:
- `/` -> Welcome Page (Get Started navigates to `/login`)
- `/login` -> Login Page (Email, Password with Eye toggle, "New user? Sign up" -> `/signup`)
- `/signup` -> Signup Page (Username, Email, Password, Confirm Password, Live Checklist, auto-redirect to `/login`)

### Run:
```bash
npm run dev
```
Visit: `http://localhost:5173/`
